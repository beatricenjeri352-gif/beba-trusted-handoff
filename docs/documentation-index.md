
# Beba Documentation

This folder contains the official product, business and technical documentation for Beba.

## Documentation structure

1. Product requirements and user journeys
2. Product decisions and decision log
3. Technical design and database architecture
4. Business model, pricing and payments
5. Testing and MVP launch

## Working principles

- Document confirmed decisions.
- Keep unresolved questions visible.
- Update documentation when decisions change.
- Ensure implementation follows approved requirements.
- Keep this repository as the main source of truth.

## Project status

Beba is currently in the product definition and technical planning stage.
The existing HTML prototype is an early demonstration, not a production application.
